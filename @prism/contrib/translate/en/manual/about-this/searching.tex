\section{How to choose a palette?}

Here are a few tips to help you select your color palette.
%
\begin{enumerate}
   \item An \thisdemo%
   \footnote{
       \thisdemourl
   }
   lets you intuitively browse palettes with the following features.
   %
   \begin{itemize}
       \item \textbf{Random discovery:} a 'random' button to explore new palettes.

       \item \textbf{Category filtering:} quickly narrow down choices by category.

       \item \textbf{Palette export:} download specific palette files directly.
   \end{itemize}


   \item Appendix \ref{palette-categos} (page \pageref{palette-categos}) details all palettes by category, showing discrete definitions (semantic/qualitative) and continuous spectra.
\end{enumerate}
