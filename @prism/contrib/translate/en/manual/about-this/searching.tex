\section{How to choose a palette?}

Here are a few tips to help you select your color palette.
%
\begin{enumerate}
   \item An \thisdemo%
   \footnote{
       \thisdemourl
   }
   provides an intuitive interface for browsing palettes with the following features.
   %
   \begin{itemize}
       \item \textbf{Random discovery:} a 'random' button to explore new palettes.
 
       \item \textbf{Category filtering:} quickly narrow down choices by category.
       
       \item \textbf{Palette export:} download specific palette files directly.
   \end{itemize}


   \item Appendix \ref{palette-categos} (page \pageref{palette-categos}) presents all palettes organized by category, including their corresponding discrete definitions for semantic and qualitative categories, and their continuous spectra for other categories.
\end{enumerate}
